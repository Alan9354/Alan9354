## Selected projects

### File Integrity Checker — CSE 325
**C++ · OpenSSL · SHA-256 · Filesystem APIs**

Implemented a command-line tool that recursively inventories files and records their sizes and SHA-256 hashes in a baseline manifest. A comparison mode reports added, removed, and modified files. The implementation includes argument validation, manifest parsing, symbolic-link handling, and error reporting.

### Concurrent Order Processing — CSE 325
**C++ · POSIX threads · Semaphores · Mutexes**

Implemented a producer-consumer order-processing program with a circular buffer. Producer threads read order files; a consumer processes orders against shared inventory. Semaphores track available and occupied buffer slots, and a mutex protects buffer updates. Command-line options configure producer count and buffer capacity.

### Cache and Memory Simulation — CSE 325
**C++ · Computer architecture**

Implemented a simulated register/cache/memory model with 16 registers, 8 cache lines, 8-byte blocks, and 64 KiB of RAM. Cache entries track valid and modified bits, tags, and block data.

### Spartanoid — CSE 335 Team Project
**C++ · wxWidgets · CMake · GoogleTest · Git/GitLab**

My contributions include player movement, boundary constraints, virtual-pixel scaling, gameplay layout integration, and documentation. I wrote four unit tests for directional movement and boundary behavior and used feature branches and merges within the shared team codebase.

### Machine Simulation and Animation — CSE 335
**C++ · wxWidgets · Object-oriented design · XML**

Extended a course animation application with machine components, an adapter connecting the machine library to the drawable hierarchy, factory-created configurations, and interface-based rotation propagation. Added timeline integration, reset/replay behavior, and XML persistence for machine selection and timing.

### Sunset Sequencer — CSE 471
**C++ · Windows MFC · Timers · Audio playback**

A coursework multimedia application with timed text/image displays, audio playback, and reset and pause/resume controls. Development included AI assistance, documented in the project’s AI-use statement. My work included planning, implementation, integration, build/startup troubleshooting, and timing/audio checks.
